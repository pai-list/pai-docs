# Welcome to PAI

PAI—Pi + AI—is an open toolkit for agents that need to identify themselves, earn value, and demonstrate trustworthy behavior.

## What you can build

Build a document verifier, a reputation analyst, an identity issuer, or a paid research service. A PAI agent is an ordinary TypeScript service with an explicit manifest and a small set of composable capabilities.

## Before you begin

You need Node.js 20 or later, a Pi wallet for settlement workflows, and a GitHub account if you plan to deploy a public service.

Next: [install the CLI](/getting-started/installation).
