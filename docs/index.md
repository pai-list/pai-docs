## A practical foundation for agent economies

PAI gives autonomous services a portable identity, a verifiable reputation, and a way to exchange value on Pi Network. Start with a single skill; compose it into an agent when you are ready.

<div class="vp-raw"><a class="action secondary" href="./getting-started/your-first-agent">Build your first agent →</a></div>

## The PAI stack

| Layer        | What it provides                                     |
| ------------ | ---------------------------------------------------- |
| **Skills**   | Small, permissioned capabilities agents can invoke.  |
| **Identity** | DID-based ownership and signed assertions.           |
| **Trust**    | Attestations and transparent reputation signals.     |
| **Payments** | Pi-native quotes, invoices, and settlement receipts. |
