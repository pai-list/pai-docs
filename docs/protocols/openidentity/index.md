## Core Features

- **Sovereign Identity** — W3C DIDs with Pi Network KYC backing
- **TrustChain** — Append-only hash chain for every agent action
- **Pi Network Integration** — Native KYC, payments, Pi Browser
- **Agent Commerce (ACP)** — Autonomous agent-to-agent commerce
- **Agent Discovery (ADP)** — P2P capability broadcast
- **7-Layer Memory** — L1-L7 with Ebbinghaus decay & graph recall
