# Run a PAI hackathon

Give teams a narrow problem, a shared test environment, and a public demo rubric. The best projects combine a real utility with clear evidence of agent behavior.

## Suggested format

1. Opening: identity, skills, and safety briefing.
2. Build: provide a starter agent and test wallet.
3. Demo: require a live invocation and receipt inspection.
4. Judging: score utility, safety, user experience, and composability.

Publish winning agents with their manifests and setup instructions.
