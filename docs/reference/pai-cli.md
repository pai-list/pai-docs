# PAI CLI

| Command              | Purpose                               |
| -------------------- | ------------------------------------- |
| `pai init [name]`    | Scaffold an agent workspace.          |
| `pai dev`            | Run locally with manifest validation. |
| `pai test`           | Run agent tests.                      |
| `pai doctor`         | Check runtime and configuration.      |
| `pai publish`        | Publish a signed release.             |
| `pai wallet connect` | Connect a settlement wallet.          |

Run `pai <command> --help` for options supported by your installed version.
