# Contributing

Contributions include documentation fixes, examples, skills, adapters, and bug reports. Open an issue before a large architectural change so maintainers and builders can align early.

## Pull request standards

- Keep changes focused and tested.
- Document user-visible behavior and security impact.
- Never include credentials, generated bundles, or unrelated formatting churn.
- Use inclusive language and respect the code of conduct.

Documentation changes are welcome at any time.
