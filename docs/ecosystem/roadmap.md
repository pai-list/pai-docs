# Roadmap

PAI is evolving in public. Priorities are guided by safe interoperability and developer experience.

| Focus                | Direction                                          |
| -------------------- | -------------------------------------------------- |
| Identity             | Stronger credential portability and key recovery.  |
| Trust                | More transparent assertion and policy tooling.     |
| Commerce             | Better recurring and escrow-like payment patterns. |
| Developer experience | Faster local testing and deployment adapters.      |

Roadmap items describe intent, not a delivery guarantee.
